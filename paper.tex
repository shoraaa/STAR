\begin{abstract}
Neural combinatorial optimization has emerged as a promising paradigm for vehicle routing, where pretrained autoregressive models construct feasible routes with low inference overhead. However, construction-trained models are commonly deployed as one-shot decoders, and repeated test-time queries on the same instance do not accumulate instance-specific feedback. Reconstruction-based inference partially addresses this limitation, but broad reconstruction can modify many edges at once, making strong local refinement expensive after each neural proposal. We propose \method{} (\methodfull{}), a test-time inference framework that uses a frozen autoregressive model as a bounded local transition model. \method{} removes a small region from the incumbent solution, reconstructs the region with the frozen model under a construction-compatible state, refines only the affected neighborhood, and updates a sparse action prior from edges introduced by accepted improvements. The neural parameters remain fixed throughout inference. On \TSP{} instances below 10K nodes, \method{} with a frozen Self-Improved Learning (\SIL{}) backbone \citep{sil} returns feasible solutions for all 178 evaluated instances, achieving a 0.09\% average gap on 69 instances below 1K nodes and a 1.31\% average gap on 109 instances from 1K to 10K nodes. These results improve over construction-only neural baselines, reconstruction-based baselines, and previously reported learned improvement baselines at this scale. The results suggest that redesigning the inference interface can substantially improve frozen autoregressive routing models without retraining.
\end{abstract}

\section{Introduction}

Vehicle routing problems are central combinatorial optimization tasks with applications in transportation, logistics, and supply-chain management. The traveling salesman problem (\TSP{}) seeks a minimum-length tour visiting each customer once, while the capacitated vehicle routing problem (\CVRP{}) further introduces depot and capacity constraints. Exact algorithms and handcrafted heuristics can produce high-quality solutions, but strong routing solvers typically require substantial domain expertise and carefully engineered search components.

Neural combinatorial optimization (\NCO{}) offers a learning-based alternative. Instead of manually designing every search component, an \NCO{} method trains a model on routing instances and uses the trained model to produce solutions for unseen instances. Autoregressive (\AR{}) models are especially common because they provide a simple construction interface: given an instance, a partial route, and a feasibility mask, the model predicts a distribution over the next node. Pointer Networks, attention models, and POMO established this construction paradigm for routing \citep{pointernetwork,attentionmodel,pomo}. Recent methods such as BQ, \LEHD{}, and Self-Improved Learning (\SIL{}) further improve construction quality and generalization through architecture, training, and inference design \citep{bq,lehd,sil}.

However, the same construction interface becomes less effective under scale and distribution shift. A model trained on short synthetic routes must make many more sequential decisions on larger or less regular instances. Greedy decoding may accumulate local errors, while sampling explores alternative trajectories without retaining information about which local choices were effective on the current instance. Reconstruction methods partly alleviate this issue by applying the model after an incumbent route is available. Nevertheless, broad reconstruction may replace many edges in a single proposal, increasing the cost of validating and refining each candidate.

This limitation is also a test-time scaling problem. In many learning systems, additional inference compute can improve performance even when model parameters are fixed. Standard neural routing inference does not fully exploit this regime: repeated sampling often revisits similar global errors, while broad reconstruction uses more compute but makes each proposal costly to repair. To improve inference scaling, the model needs a smaller unit of reuse. Each neural call should affect a bounded part of the incumbent, and the solver should convert successful local changes into information that affects later calls on the same instance.

To this end, we propose \method{} (\methodfull{}), a scoped inference framework for frozen neural routing models. \method{} maintains an incumbent solution, the best solution found so far, and a sparse memory table over edges. At each iteration, it selects a local region, queries the frozen model to reconstruct only this region, applies scope-restricted refinement around the affected edges, and accepts the refined proposal if it improves the incumbent. The memory update, \ACM{}, credits edges introduced by accepted improving perturbations. Unlike reinforcement of the whole incumbent route, this update targets the intervention that changed the solution.

Comprehensive experiments are conducted on \TSP{} instances below 10K nodes using a frozen \SIL{} backbone. The results show that \method{} improves over construction-only neural inference, reconstruction-based inference, and previously reported learned improvement baselines at this scale. Additional diagnostic experiments study inference scaling, component importance, memory design, scope sensitivity, and plug-and-play behavior across frozen backbones. These analyses indicate that \method{} is not only a high-performing routing heuristic, but also a test-time adaptation mechanism that makes frozen autoregressive models more useful under length extrapolation.

Our contributions are as follows:
\begin{enumerate}[leftmargin=*,noitemsep]
  \item We identify a test-time feedback bottleneck in frozen autoregressive routing inference, where repeated model calls do not create persistent instance-specific preferences.
  \item We introduce \method{}, a scoped inference framework that combines context-preserving perturbation, advantage-credit memory, and scope-restricted refinement.
  \item We provide an empirical analysis of how local neural proposals, scoped refinement, and sparse memory interact, including component-wise ablations, memory-design comparisons, and sensitivity studies.
  \item We evaluate \method{} with a frozen \SIL{} backbone on \TSP{} instances below 10K nodes, showing consistent gains over construction-only inference, reconstruction baselines, and prior learned improvement methods.
\end{enumerate}

\section{Related Work}

Neural routing methods can be broadly grouped into constructive approaches, reconstruction-based approaches, decomposition or local-policy approaches, and learned improvement methods. This work focuses on constructive autoregressive models and studies how such models can be reused at inference time without updating their parameters.

\subsection{Autoregressive Neural Construction}

Autoregressive models construct routing solutions one decision at a time. Pointer Networks introduced sequence-to-sequence construction for combinatorial optimization, and attention-based routing models made this approach a standard neural baseline \citep{pointernetwork,attentionmodel}. POMO improves training and inference by exploiting multiple equivalent optima \citep{pomo}. BQ, \LEHD{}, and \SIL{} further improve construction and generalization through decoder-heavy architectures, supervised learning, self-improved learning, and reconstruction-oriented inference \citep{bq,lehd,sil}. In contrast, \method{} assumes that such a model is already trained and modifies the test-time loop around the frozen checkpoint.

\subsection{Reconstruction at Inference Time}

Inference-time reconstruction repairs an existing solution instead of constructing a route only once. Reconstruction variants of \LEHD{} and \SIL{} show that autoregressive decoders contain useful conditional structure beyond greedy construction \citep{lehd,sil}. \method{} is closely related to this line of work, but it uses a smaller repair unit. Rather than reconstructing a broad segment, \method{} decodes a bounded local transition and immediately refines the affected neighborhood.

\subsection{Decomposition and Local Policies}

Large routing instances are often handled by reducing the effective problem size. H-TSP and GLOP decompose or localize the instance before applying a neural solver \citep{htsp,glop}. Local-policy methods such as INViT transform candidate neighborhoods before model evaluation \citep{invit}. These methods address scale by changing the input presented to the model. \method{} addresses a complementary question: once a complete solution exists, how can a frozen model be reused adaptively on the same instance?

\subsection{Neural Guidance for Improvement}

Heatmap-based and learned-improvement methods use neural predictions to guide search procedures. DIFUSCO, GFACS, and NeuroLKH are representative examples of learned signals embedded into stronger improvement pipelines \citep{difusco,gfacs,neurolkh}. \method{} follows the same general direction of using learned information inside search, but it preserves the autoregressive action interface. The sparse memory table maps local search feedback to logit shaping for future model calls.

\subsection{Test-Time Adaptation and Inference Scaling}

Test-time adaptation studies how a fixed model can improve on a particular input distribution or instance without full retraining. In routing, this question is especially important because a single instance can be queried many times, and the value of a local decision is only observed after it interacts with search. \method{} treats this setting as an inference-scaling problem: additional test-time compute should produce better solutions, but only if the inference loop converts repeated model calls into directed search rather than independent rollouts.

\section{Preliminaries}

\subsection{Routing Instances}

Let $x$ be a Euclidean routing instance on node set $V=\{0,\ldots,n-1\}$. A feasible solution $y\in\cY(x)$ induces an edge set or multiset $E(y)$. The objective value is
\begin{equation}
  \cost_x(y)=\sum_{(i,j)\in E(y)}d_x(i,j),
  \label{eq:cost}
\end{equation}
where $d_x(i,j)$ denotes the benchmark distance between nodes $i$ and $j$. Given a reference cost $\cost_x^\star$, the percentage optimality gap is
\begin{equation}
  \gap_x(y)=100\cdot\frac{\cost_x(y)-\cost_x^\star}{\cost_x^\star}.
  \label{eq:gap}
\end{equation}

\subsection{Frozen Autoregressive Models}

An autoregressive model with parameters $\theta$ constructs a solution through states $s_t$ and actions $a_t$:
\begin{equation}
  P_\theta(y\mid x)=\prod_{t=1}^{T(x,y)}P_\theta(a_t\mid x,s_t),
  \qquad a_t\in\cA(x,s_t).
  \label{eq:ar}
\end{equation}
The state contains the partial route, current node, visited mask, and feasibility variables. We denote the frozen model logit for action $a$ by $\ell_\theta(a\mid x,s)$.

\begin{definition}[Frozen-model inference]
An inference method is a frozen-model inference method if it may query $P_\theta$ but does not update $\theta$. It may update external solver states, including incumbent solutions, candidate lists, caches, and non-neural memory.
\end{definition}

\section{Motivation: Test-Time Feedback and Length Extrapolation}
\label{sec:bottleneck}

A frozen autoregressive model does not maintain memory across independent decoder calls. When a local reconstruction improves an incumbent solution, the outer solver observes the improvement, but the model distribution remains unchanged. Sampling repeats the same learned distribution, while reconstruction changes the state distribution without creating persistent local preferences.

A second limitation concerns repair scope. A long reconstruction can replace many edges, which increases the cost of validating and refining each proposal. A short move is cheaper to repair, but it may be too weak if it is purely heuristic. The desired inference unit should therefore use the neural model for bounded local transitions while applying local search only around the edges affected by those transitions.

This mismatch can be viewed as a gap between the temporal scale of model decisions and the temporal scale of search feedback. The model emits one action at a time, whereas the solver observes whether a complete perturbation, after refinement, improves the route. An effective inference algorithm should assign credit to local structural changes rather than to an entire trajectory. It should also preserve the construction interface under which the model was trained, since replacing the decoder with a handcrafted move operator would discard the learned conditional information.

The same design also addresses length extrapolation. A construction model trained on short routes may be asked to produce thousands of decisions when applied to large instances. In \method{}, the global instance can be large, but each neural query is restricted to at most $r$ local actions. The model therefore solves a sequence of small conditional construction problems rather than a single long out-of-distribution trajectory. Global coordination is handled by the incumbent route, the sequence of accepted transitions, and the memory table.

Accordingly, the inference unit used in \method{} has three properties. First, it is context preserving: the frozen model receives a construction-compatible state and a feasible-action mask. Second, it is scope bounded: the decoded region has size controlled by $r$, so refinement cost depends on local structure rather than the full instance. Third, it is feedback carrying: successful local transitions influence future model calls through a sparse action prior.

\section{Methodology}
\label{sec:method}

\subsection{Method Framework}

\method{} maintains an incumbent solution $y_t$, a best-so-far solution $y_t^\star$, and a sparse memory table $M_t:\cE\rightarrow[-M_{\max},M_{\max}]$. Each iteration selects a local region, queries the frozen model on this region, refines the resulting route locally, accepts an improving candidate, and updates memory from the accepted perturbation.

The framework separates three components. The neural model provides conditional structure by ranking feasible next nodes in a local state. The refinement operator restores local consistency by removing short-range defects introduced by the neural proposal. The memory table provides test-time adaptation by biasing future local decisions toward transitions that have already produced improvement on the same instance. These components have complementary computational profiles: neural decoding proposes structured local transitions, refinement evaluates their immediate geometric consequences, and memory accumulates instance-specific evidence without modifying the neural parameters.

The memory table is external to the neural network. It can be initialized, cleared, clipped, or inspected without changing the model parameters. Thus, \method{} can be applied to frozen checkpoints and to settings where retraining or gradient-based adaptation is unavailable.

\subsection{Context-Preserving Perturbation}

Let $R_t\subseteq V$ be the removed node set at iteration $t$, with $|R_t|\le r$. Let $(u_t,v_t)$ denote the anchors around the removed region. The local state is
\begin{equation}
  s^{\CPP}_0=(x,\ y_t\setminus R_t,\ u_t,\ v_t,\ R_t,\ \text{mask},\ \text{feasibility state}).
  \label{eq:cpp}
\end{equation}
The decoder selects a sequence $\sigma_t=(a_1,\ldots,a_m)$ from $R_t$. The local transition replaces the anchor connection by
\begin{equation}
  (u_t,v_t)\mapsto (u_t,a_1),(a_1,a_2),\ldots,(a_m,v_t),
  \label{eq:splice}
\end{equation}
while leaving the remaining route unchanged before refinement.

The state in Eq.~\eqref{eq:cpp} is a restricted construction state. The route context, current anchor, visited mask, and feasible-action mask are represented in the same form as ordinary autoregressive decoding, while nodes outside $R_t$ are fixed as context. The model therefore selects plausible transitions within a small feasible set under its learned sequential structure. By construction, every local decode contains at most $r$ actions, independent of the global instance size.

For \TSP{}, this perturbation corresponds to a local route splice. For \CVRP{}, the same principle requires route-boundary information and remaining capacity in the local mask. The experiments in this work focus on \TSP{}, where the feasibility state is limited to visitation constraints.

\subsection{Advantage-Credit Memory}

Let $\phi(s,a)$ be the set of edges introduced when action $a$ is selected in state $s$. The memory score is
\begin{equation}
  G_t(s,a)=\frac{1}{\max(1,|\phi(s,a)|)}\sum_{e\in\phi(s,a)}M_t(e).
  \label{eq:memory-score}
\end{equation}
The shaped model distribution is defined as
\begin{equation}
  \widetilde P_t(a\mid x,s)=
  \frac{
  \exp((\ell_\theta(a\mid x,s)+\lambda_tG_t(s,a)-\beta\Delta c(s,a))/\tau_t)
  }{
  \sum_{b\in\cA(x,s)}
  \exp((\ell_\theta(b\mid x,s)+\lambda_tG_t(s,b)-\beta\Delta c(s,b))/\tau_t)
  }.
  \label{eq:shaped}
\end{equation}
Here $\lambda_t$ controls the memory strength, $\beta$ controls the distance feature, and $\tau_t$ denotes the sampling temperature. The feature $\Delta c(s,a)$ is a normalized one-step insertion proxy. If $p_s$ denotes the current endpoint in the local reconstruction and $v_t$ denotes the terminal anchor, we compute
\begin{equation}
  \Delta c(s,a)=\frac{d_x(p_s,a)+d_x(a,v_t)-d_x(p_s,v_t)}{\bar d_x},
  \label{eq:insertion}
\end{equation}
where $\bar d_x$ is the mean distance over the local candidate list. This term is not a learned component; it is a test-time geometric prior that discourages obviously expensive insertions when the masked action set contains several plausible neural choices.

Given a source route $y_t$ and refined candidate $\hat y_t$, define
\begin{equation}
  A_t(\hat y_t;y_t)=
  \frac{\cost_x(y_t)-\cost_x(\hat y_t)}{\max(\cost_x(y_t),\epsilon)}
  \label{eq:advantage}
\end{equation}
and the introduced edges as
\begin{equation}
  \Delta E_t^+=E(\hat y_t)\setminus E(y_t).
  \label{eq:introduced}
\end{equation}
\ACM{} updates memory according to
\begin{equation}
  M_{t+1}(e)=
  \begin{cases}
  \clip(M_t(e)+\eta A_t(\hat y_t;y_t),-M_{\max},M_{\max}),
  & \text{if } A_t(\hat y_t;y_t)>0 \text{ and } e\in\Delta E_t^+,\\
  M_t(e), & \text{otherwise.}
  \end{cases}
  \label{eq:update}
\end{equation}

The update is positive-only in the reported experiments. Non-improving proposals are not treated as negative evidence because an unsuccessful refined solution may arise from the selected scope, the decoded sequence, the refinement neighborhood, or the quality of the incumbent. In contrast, an accepted improvement provides a cleaner credit signal. The clipping threshold prevents a small number of early improvements from dominating the frozen logits throughout inference.

The memory score in Eq.~\eqref{eq:memory-score} is normalized by the number of introduced edges represented by the action. This avoids assigning larger scores to actions only because they touch more memory entries. Since every memory entry is clipped to $[-M_{\max},M_{\max}]$, the absolute memory-induced logit shift is bounded by $\lambda_tM_{\max}$. Thus, memory can guide the frozen model without silently replacing its learned logits unless $\lambda_t$ is deliberately set large.

\subsection{Scope-Restricted Refinement}

Let $D_t$ and $I_t$ denote the deleted and inserted edges from a local transition. The affected endpoints are
\begin{equation}
  A_t^{\mathrm{end}}=\{i:\exists j,\ (i,j)\in D_t\cup I_t \text{ or } (j,i)\in D_t\cup I_t\}.
  \label{eq:endpoints}
\end{equation}
With candidate lists $\cN_K(i)$, the refinement region is
\begin{equation}
  \Omega_t=A_t^{\mathrm{end}}\cup\bigcup_{i\in A_t^{\mathrm{end}}}\cN_K(i).
  \label{eq:scope}
\end{equation}
For \TSP{}, \SRR{} evaluates restricted 2-opt, relocate, Or-opt, and swap moves touching this scope.

The operator follows the locality principle of the scope-restricted refinement mechanism used in \DyNACO{} \citep{dynaco}, where local refinement was introduced for perturbation-based ACO guided by non-autoregressive heatmap-based neural signals. In that setting, the neural output is an edge-level prior inside an ACO backend, and \SRR{} preserves credit assignment by repairing only the neighborhood touched by an ant perturbation. In \method{}, the neural proposal is instead produced by an autoregressive decoder over a masked local construction state.

This distinction affects both interpretation and implementation. In \DyNACO{}, \SRR{} preserves the relationship between heatmap-guided edge choices and post-refinement cost. In \method{}, it preserves the relationship between a decoded local sequence and the accepted incumbent transition. Accordingly, the refinement scope is tied to the deleted and inserted endpoints from the autoregressive splice. The operator repairs the local geometry of candidates generated by the frozen model rather than replacing the model with a separate proposal mechanism.

\SRR{} serves as a local projection step rather than a full local-search solver. Its role is to make each neural proposal locally sharp enough for evaluation. A proposal that inserts the right nodes in an awkward order can often be repaired by moves around the changed edges. Conversely, a bounded perturbation should not damage distant parts of the route. For this reason, the scope is defined by deleted and inserted endpoints rather than by a fixed route-order window. If each perturbation modifies at most $r$ nodes and each affected endpoint exposes at most $K$ candidate neighbors, the number of local move combinations per pass is tied to $r$ and $K$, rather than to the global instance size.

\subsection{Acceptance and Algorithmic Properties}

The reported experiments use improve-only acceptance:
\begin{equation}
  y_{t+1}=
  \begin{cases}
  \hat y_t, & \cost_x(\hat y_t)<\cost_x(y_t),\\
  y_t, & \text{otherwise.}
  \end{cases}
  \label{eq:accept}
\end{equation}
The best-so-far solution $y_t^\star$ is updated whenever the accepted incumbent improves its cost.

Several useful properties follow directly from the algorithm design. First, the local decoding horizon is bounded by $r$ because the mask permits only nodes in $R_t$. Second, memory values remain bounded because every update is clipped to $[-M_{\max},M_{\max}]$. Third, for fixed outer budget $B$, proposal count $S$, and perturbation size $r$, the method performs at most $BSr$ autoregressive action selections, excluding implementation-specific encoder caching. Fourth, improve-only acceptance gives a monotone anytime incumbent: the cost of the incumbent and best-so-far route never increases during a run. These properties are not intended as deep theoretical claims; they clarify the computational and optimization behavior of the inference loop.

\subsection{Algorithm}

\begin{algorithm}[t]
\caption{\method{} inference with a frozen autoregressive model.}
\label{alg:star}
\small
\begin{algorithmic}[1]
\REQUIRE Instance $x$, frozen model $P_\theta$, initial solution $y_0$, budget $B$, perturbation size $r$, candidate width $K$, proposals $S$
\STATE Initialize $y \leftarrow y_0$, $y^\star \leftarrow y_0$, and $M(e)\leftarrow 0$
\STATE Build candidate lists $\cN_K(i)$
\FOR{$t=1,\ldots,B$}
    \STATE Select removed set $R_t$ and anchors $(u_t,v_t)$
    \STATE Decode $S$ local sequences under the shaped distribution in Eq.~\eqref{eq:shaped}
    \STATE Splice each sequence into the incumbent route
    \STATE Apply \SRR{} to each candidate within $\Omega_t$
    \STATE Let $\hat y_t$ be the best refined candidate
    \IF{$\cost_x(\hat y_t)<\cost_x(y)$}
        \STATE Update $M$ with \ACM{} using introduced edges
        \STATE $y\leftarrow \hat y_t$
        \IF{$\cost_x(y)<\cost_x(y^\star)$}
            \STATE $y^\star\leftarrow y$
        \ENDIF
    \ENDIF
\ENDFOR
\STATE \textbf{return} $y^\star$
\end{algorithmic}
\end{algorithm}

\section{Experiments}
\label{sec:experiments}

\subsection{Experimental Questions}

The evaluation is designed to answer four questions. First, does \method{} improve the final solution quality of a frozen autoregressive backbone on larger \TSP{} instances? Second, does the method make better use of additional test-time compute than standard sampling or broad reconstruction? Third, which components are responsible for the improvement: neural local proposals, scoped refinement, or memory? Fourth, how sensitive is the method to the local scope, refinement width, and memory strength?

\subsection{Problem Setting}

The empirical evaluation focuses on \TSP{} instances below 10K nodes. The small group contains 69 instances with fewer than 1K nodes, and the medium group contains 109 instances with 1K to 10K nodes. The objective is to test whether \method{} improves a pretrained neural backbone as the instance size increases.

\subsection{Model and Inference Setting}

The neural backbone is the pretrained \TSP{} model from Self-Improved Learning \citep{sil}. All neural weights are fixed during inference. The main evaluation uses 90 outer iterations, 100 neural proposals per iteration, a minimum new-edge threshold of 16, hybrid start mode, and source-advantage \ACM{} mode. Here, source-advantage means that the scalar advantage in Eq.~\eqref{eq:advantage} is measured against the pre-perturbation source route; the credited entries are still the introduced edges in Eq.~\eqref{eq:introduced}. Details on the backbone, local state construction, and inference hyperparameters are provided in the appendix.

\subsection{Sensitivity to Local Scope and Refinement Width}

The perturbation size $r$ controls how many nodes the neural model can rearrange in one local transition. Very small values are stable but may not expose enough structure to escape a local basin. Very large values give the model more freedom, but they increase decoding difficulty and refinement cost. Figure~\ref{fig:sensitivity-rk} shows the expected Goldilocks behavior: performance improves as $r$ increases from very small scopes, reaches its best region near the middle, and then degrades as the repair problem becomes too broad.

The candidate width $K$ controls the reach of \SRR{}. Small $K$ keeps refinement cheap but misses useful local moves. Large $K$ improves local repair quality but increases local move evaluations. The expected curve therefore decreases initially and then plateaus, indicating that very wide candidate lists provide diminishing returns.

\section{Discussion}

The results support the view that \method{} improves frozen neural routing through three interacting mechanisms. First, the local mask changes the extrapolation problem. Instead of decoding a route whose length grows with $n$, the model repeatedly solves conditional subproblems of size at most $r$. Second, \SRR{} converts plausible neural sequences into locally competitive candidates, preventing small geometric defects from dominating the acceptance decision. Third, \ACM{} transforms accepted local improvements into a bounded prior over future actions, allowing repeated inference calls to accumulate instance-specific evidence.

The component ablation clarifies the division of labor. Without refinement, neural proposals are too noisy to compete reliably with an improved incumbent. Without neural logits, \SRR{} can still improve routes, but it starts from weaker local rearrangements and does not reach the same gap. Without memory, the solver still benefits from local neural reconstruction, but it has a higher repeat-proposal rate and converges more slowly. Thus, the method is not simply a local-search heuristic attached to a neural model, nor is it a neural decoder with a cosmetic memory term. The performance depends on the interaction between learned proposal structure, local projection, and feedback-guided reuse.

The memory diagnostics further show why introduced-edge credit is preferable to source-route reinforcement. Source-route memory asks which edges are present in a good incumbent, but this includes many unchanged edges that did not participate in the recent improvement. \ACM{} asks a more local question: which new edges were introduced by an improving intervention? This is closer to the credit-assignment unit observed by the solver. The expected repeat-proposal and saturation diagnostics provide two practical checks. A useful memory mechanism should reduce repeated dead-end proposals, but it should not saturate so quickly that it overwrites the frozen model.

The scope sensitivity analysis also identifies the main limit of the method. If $r$ is too small, the model can only express narrow local moves, and the search may stagnate. If $r$ is too large, the local reconstruction problem becomes closer to broad segment decoding, which increases noise and refinement cost. Similarly, increasing $K$ improves \SRR{} only until the affected neighborhood is sufficiently covered. These trends support the central design choice: the method should remain local, but not so local that the neural model has no meaningful structure to reconstruct.

Finally, \method{} should be interpreted as a learned inference interface rather than as a replacement for classical optimization. LKH-3 remains a strong optimization reference. The contribution of \method{} is different: it shows that a frozen autoregressive model can obtain substantially better zero-shot behavior when test-time compute is organized as scoped adaptation rather than as independent sampling or broad reconstruction. This framing is important for future work on neural combinatorial optimization, where improving the inference loop may be as effective as changing the training procedure.

\section{Conclusion, Limitations, and Future Work}

We presented \method{}, a scoped test-time framework for frozen autoregressive routing models. The method uses a pretrained model to propose bounded local transitions, applies \SRR{} to restore local consistency, and uses \ACM{} to store instance-specific credit for introduced improving edges. Experiments on \TSP{} instances below 10K nodes show that this inference interface improves over construction-only neural models, reconstruction baselines, and prior learned improvement methods without updating neural weights.

The current evaluation is limited to \TSP{} instances below 10K nodes with a frozen \SIL{} backbone, while several diagnostic and cross-backbone runs are still in progress. Extending \method{} to \CVRP{} requires capacity-aware local states, route-boundary information, and capacity-preserving refinement moves. Scaling to larger \TSP{} instances requires a hardware-controlled runtime protocol and a more detailed accounting of candidate-list construction, neural evaluation, and local refinement. Future work should evaluate additional frozen backbones, report multi-seed variance for stochastic proposal sampling, compare normalized runtime on shared hardware, and study adaptive scope selection.

\section{Detailed Component Algorithms}

\begin{algorithm}[h]
\caption{Context-preserving perturbation.}
\label{alg:cpp}
\small
\begin{algorithmic}[1]
\REQUIRE Incumbent route $y$, perturbation size $r$, start mode
\STATE Select a route position according to the start mode
\STATE Expand around it until at most $r$ removable nodes are selected
\STATE Record removed nodes $R$ and anchors $(u,v)$
\STATE Remove $R$ from the route while preserving all other order
\STATE Build a decoder mask that permits only nodes in $R$
\STATE \textbf{return} $R,(u,v)$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[h]
\caption{\ACM{} update.}
\label{alg:acm}
\small
\begin{algorithmic}[1]
\REQUIRE Source route $y$, candidate route $\hat y$, memory table $M$
\STATE Compute advantage $A$ from Eq.~\eqref{eq:advantage}
\IF{$A\le0$}
    \STATE \textbf{return} $M$
\ENDIF
\STATE Compute introduced edges $\Delta E^+$
\FOR{$e\in\Delta E^+$}
    \STATE $M(e)\leftarrow\clip(M(e)+\eta A,-M_{\max},M_{\max})$
\ENDFOR
\STATE \textbf{return} $M$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[h]
\caption{\SRR{} for autoregressive local transitions.}
\label{alg:srr}
\small
\begin{algorithmic}[1]
\REQUIRE Candidate route $\hat y$, deleted edges $D$, inserted edges $I$, candidate lists $\cN_K$, move cap $h$
\STATE Initialize affected endpoints $A^{\mathrm{end}}$ from $D\cup I$
\STATE Build $\Omega=A^{\mathrm{end}}\cup\bigcup_{i\in A^{\mathrm{end}}}\cN_K(i)$
\STATE Initialize a checklist with nodes in $\Omega$
\WHILE{the checklist is nonempty and fewer than $h$ moves have been accepted}
    \STATE Evaluate improving 2-opt, relocate, Or-opt, and swap moves touching $\Omega$
    \IF{an improving scoped move exists}
        \STATE Apply the best move and add newly affected endpoints to the checklist
    \ELSE
        \STATE Remove the exhausted node from the checklist
    \ENDIF
\ENDWHILE
\STATE \textbf{return} $\hat y$
\end{algorithmic}
\end{algorithm}

\section{Diagnostics and Compatibility}

\paragraph{Masked local decoding.}
\method{} depends on querying the declared frozen model under a local mask. When the model cannot yield logits for a masked state, the corresponding proposal is unsupported and should not be replaced by a heuristic fallback. This convention preserves a clear evaluation of the frozen neural proposal mechanism and avoids conflating learned local transitions with handcrafted proposal rules.

\paragraph{Perturbation reach.}
When the perturbation size is too small, repeated local proposals may tie the source solution without escaping the current basin. This appears as many accepted ties or rejected non-improvements. Increasing the perturbation size can help, but it also makes local reconstruction harder. The sensitivity study therefore varies both $r$ and $K$.

\paragraph{Memory saturation.}
The clipping rule prevents unbounded memory growth, but saturation can still reduce adaptivity if many edges reach the clipping threshold early. The expected memory distribution in Figure~\ref{fig:memory-dist} is included as a diagnostic template. If the completed run shows that most nonzero entries saturate, the memory strength $\lambda_t$, step size $\eta$, or clipping threshold $M_{\max}$ should be reduced.

\paragraph{Refinement locality.}
\SRR{} assumes that most damage from a bounded neural transition is near the deleted or inserted edges. If this assumption fails, the scoped move set may miss improvements that a full local search would find. The candidate width $K$ controls this tradeoff: larger values expand the searchable neighborhood but increase the number of local move evaluations.

\paragraph{Compatibility requirements.}
Applying \method{} to a frozen model requires four implementation properties:
\begin{itemize}[leftmargin=*,noitemsep]
  \item \textbf{Masked local logits:} the model must expose a proposal distribution over a bounded feasible set.
  \item \textbf{Stable route context:} the model state must contain enough information to interpret anchors and removed nodes.
  \item \textbf{Feasible splice operation:} the decoded local sequence must be insertable into the incumbent route.
  \item \textbf{Problem-aware refinement:} the refinement step must preserve the constraints of the routing problem.
\end{itemize}
These requirements are mild for autoregressive \TSP{} construction models with explicit masks, but they become more restrictive for constrained routing variants or architectures that do not expose local logits.

\section{Design Rationale}

Constructive neural solvers learn a mapping from partial routing states to next-node decisions. Their main advantage is fast inference once a model has been trained. However, ordinary construction is irreversible: an early poor edge changes the future feasible set and forces later decisions to compensate. Beam search and sampling mitigate this issue by maintaining multiple trajectories, but they still use the model as a trajectory generator. \method{} retains the constructive decoder while changing its role. The model repeatedly completes small local construction states, while the incumbent route supplies context and the outer search supplies feedback.

This design is closely related to large-neighborhood search, which destroys part of a solution and repairs it. \method{} follows the same high-level structure, but its repair operator is a frozen autoregressive model queried under a context-preserving local state. If the repair problem is too large, neural decoding becomes expensive and noisy. If it is too small, the repair resembles a handcrafted local move. \method{} chooses an intermediate regime in which the repair is local enough for immediate refinement but structured enough for the neural model to contribute learned conditional information.

The memory representation also reflects this local-search view. Actions are state-dependent: the same node choice can represent different structural changes depending on the current anchor and mask. Edges provide a more stable representation of route structure. \ACM{} therefore stores edge credit and maps it back to action scores through $\phi(s,a)$. This creates a lightweight memory that is independent of the internal parameterization of the frozen model.

Positive credit and improve-only acceptance provide a conservative anytime search behavior. Negative credit is tempting, but the signal from a failed proposal is ambiguous. A proposal may fail because the removed region was poorly chosen, the neural sequence was weak, refinement was too narrow, or the incumbent was already locally strong. Positive improvements provide clearer evidence: they identify transitions that survived refinement and reduced cost. Improve-only acceptance gives the method a monotone anytime interpretation, at the cost of reduced exploration.

\section{Extension to Capacitated Routing}

\method{} applies to \CVRP{} after the local state and refinement operator become capacity-aware. The local state must include depot position, route boundaries, customer demands, and remaining route capacity. The decoder mask must prevent infeasible insertions. The refinement step must use capacity-preserving relocate, swap, and cross-route moves. These requirements preserve the conceptual framework while adapting the feasibility machinery to capacitated routing.

\section{Broader Impact}

Routing optimization has applications in logistics, transportation, and infrastructure planning. Improvements in route quality can reduce travel distance and operational cost. At the same time, optimization systems may be used in settings where efficiency objectives interact with labor constraints, privacy, fairness, and environmental considerations. This work is methodological and benchmark-focused, but deployment should account for these downstream factors.
